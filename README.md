# T California Dental Lab Warranty QR Site

This repository contains a simple static website for dental warranty cards.

## Files
- `index.html` — admin / QR generator page
- `warranty.html` — patient-facing lifetime warranty card
- `patients.json` — patient records used by the QR card page

## How to use
1. Open `index.html` in a browser.
2. Add a patient, then generate a QR code.
3. Scan the QR or open `warranty.html?id=P-1001`.
4. Host the files on GitHub Pages or any static host.

## GitHub Pages setup
1. Push these files to the `main` branch.
2. In GitHub → Settings → Pages → Source, choose `Deploy from a branch`.
3. Pick branch `main` and folder `/root`.
4. Save. The site URL will be `https://<username>.github.io/<repo>/`.
